# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

**1.0.0** is the current package. Later edits stay on 1.0.0 until that package is released.

## [1.0.0] — 2026-11-20

### Added

- Using a golden chest spends one golden key and opens the chest. The game does not ask if you are sure. Borderlands 2 and The Pre-Sequel.
- **Skip the key question** starts on. Turn it off and the game asks again. Other yes or no questions are left alone.
- The same file works when you joined someone else. A player without the mod still gets the question.
- Repository docs under `docs/`, plus LICENSE, SECURITY, CONTRIBUTING, and `.gitignore`. The package lives in `src/Use_Golden_Key`.
