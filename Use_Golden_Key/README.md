Using a golden chest spends one golden key and opens the chest. The game does not ask "are you sure you want to spend a golden key?"

It runs in Borderlands 2 and in Borderlands: The Pre-Sequel. Other yes or no questions are left alone. Turn **Skip the key question** off if you want the question back.

## Install

1. Willow2 Mod Manager v3.8 is already what Modern Movement uses. This mod needs that too.
2. Copy `Use_Golden_Key.sdkmod` into the game's `sdk_mods` folder.
3. Enable **Use Golden Key** and restart the game.

The same file goes in both games. A player who does not have it still gets the question. A player who has it spends their own key without the question, including when they joined someone else.
