# Use Golden Key 1.0.0

The same file runs in Borderlands 2 and Borderlands: The Pre-Sequel. Using a golden chest spends one golden key and opens the chest. The game does not ask if you are sure. Other yes or no questions stay as they are.

**Package:** `dist/Use_Golden_Key.sdkmod`  
**SHA-256:** `28fe4facd0d9fb1369c6864d0aed1e6fb6f72f80e709e10a93da451df62dc1ad`

Install this file in that game's `sdk_mods` folder. Confirm the hash against `dist/Use_Golden_Key.sdkmod.sha256` before enabling it. Use the same file on Borderlands 2 and on The Pre-Sequel. Leave the hash file and the manifest out of the game folder.

## Highlights

- The golden chest spends a key and opens. The confirmation is not shown.
- **Skip the key question** starts on. Turn it off and the game asks again.
- If the spend cannot go through, the question still shows.
- A player without the mod still gets the question. Someone else's copy does not spend their key.
